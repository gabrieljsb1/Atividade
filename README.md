1. Download e Instalação do Git 

Baixar e instalar: Acesse o site oficial do Git ([git-scm.com/downloads](https://git-scm.com/downloads)), baixe o instalador para Windows e conclua o processo de instalação. 

Abrir o Git Bash: Inicie o terminal nativo do Git (Git Bash). 

Verificar instalação: Execute o comando para conferir se o Git foi instalado corretamente: 

Bash 

git --version
